# Ordinal brand CDN

Public images for Ordinal HTML emails. Gmail and Outlook only show images served over HTTPS, so emails link here through raw.githubusercontent.com.

- `logos/ordinal-logo-white.png`: white logo, 480 x 145, for dark surfaces.
- `email/welcome-hero.jpg`: welcome email header (logo, brandbook gradient and geometry), 1200 x 400, shown at 600 x 200.
- `email/welcome-gift.jpg`: gift card band, 1008 x 240, shown at 504 x 120.

URL pattern: `https://raw.githubusercontent.com/buildwithordinal/brand-cdn/main/<path>`

Only public brand assets go here. No client data, no internal documents.
